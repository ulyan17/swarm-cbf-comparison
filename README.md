Репозиторий содержит код и данные для воспроизведения экспериментов, описанных в статье **«Сравнительный анализ классического CBF, кристаллического алгоритма и обученной графовой нейросети GCBF+ для децентрализованного управления роем мобильных агентов»**.

## Аннотация

Проведено прямое количественное сравнение трёх подходов к децентрализованному управлению группой мобильных агентов: классического метода на основе барьерных функций (CBF), кристаллического алгоритма с потенциалами Леннарда-Джонса и обученной графовой нейросети GCBF+. Эксперименты выполнены в единой среде с одинаковыми ограничениями для групп из 5, 10 и 20 агентов. Установлено, что CBF обеспечивает наилучшую безопасность (96,3% агентов достигают целей при 20 агентах), но время шага достигает 81,7 мс. Кристаллический алгоритм сохраняет постоянное время (1,6 мс), однако допускает 33,3 парных столкновений на эпизод. GCBF+ при малых группах близок к CBF по качеству и значительно быстрее (5,4 мс при 20 агентах), но его успешность падает до нуля при числе соседей в графе более 6, что выходит за пределы обучающего распределения. Выявлены механизмы нарушения гарантий CBF: насыщение управления (19% шагов) и использование slack-переменных (31% шагов). Полученные результаты количественно характеризуют компромисс между безопасностью, точностью и вычислительной сложностью и указывают на критическую важность согласования обучающего и рабочего распределений для обучаемых контроллеров.

## Установка

Требуется Python 3.9+ . Рекомендуется создать виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows
Установите зависимости:

bash
pip install -r requirements.txt
Основные библиотеки: NumPy, SciPy, Matplotlib, PyTorch 2.0.1, Pandas, Seaborn, Statsmodels.
Воспроизведение экспериментов
1. Обучение модели GCBF+
Обучение выполняется на 50 000 случайных сценах с 2–6 агентами. Готовая модель уже сохранена в experiments/50k/gcbf_model.pt. Чтобы переобучить модель заново:

bash
python src/train_gcbf.py --exp_name 50k --num_scenes 50000 --num_epochs 300
Выходные файлы (датасет и веса) будут помещены в experiments/50k/.

2. Запуск сравнительного эксперимента
Для сбора метрик на тестовых сценариях (5, 10, 20 агентов, по 30 случайных конфигураций каждый):

bash
python run_comparison.py
Результаты сохранятся в comparison_results.csv. Для ускорения можно изменить параметры N_list и num_seeds в начале файла.

3. Визуализация движения агентов
Чтобы увидеть работу любого из контроллеров в реальном времени:

bash
python demo.py --controller CBF --agents 10
python demo.py --controller Crystal --agents 10
python demo.py --controller GCBF+ --agents 10
Поддерживаются значения --agents 5, 10, 20 и контроллеры CBF, Crystal, GCBF+. Окно matplotlib покажет траектории агентов, цели (зелёные крестики) и препятствия (серые круги).

4. Статистический анализ и графики
После завершения run_comparison.py выполните:

bash
python analysis.py
Скрипт рассчитает парные тесты (Фридман, Уилкоксон, Мак-Немар) с коррекцией FDR, построит все графики и сохранит их в корне проекта (или в папке results/). Основные таблицы и графики используются в статье.

Использование результатов
Все собранные метрики и графики находятся в папке results/. Вы можете свободно использовать их в своих исследованиях при условии ссылки на оригинальную статью.
